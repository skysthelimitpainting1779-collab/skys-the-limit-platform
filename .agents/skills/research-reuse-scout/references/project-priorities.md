# Sky's native-first research priorities

- Convex: inspect Components and official patterns for workflows, migrations,
  rate limiting, presence, aggregates, agents, scheduling, and persistent
  reusable backend modules before custom stateful infrastructure.
- Vercel: inspect native Git/Preview/deployment features, Integrations
  Marketplace, templates, observability, Workflow, and Blob before another
  infrastructure vendor.
- GitHub: inspect Issues, sub-issues, Projects, Actions, environments, rulesets,
  security, Dependabot, code scanning, and artifacts before a local control plane.
- UI: inspect existing components/design system, shadcn primitives and reviewed
  registries, and Base UI before another generic block.
- Agent infrastructure: inspect Codex, Antigravity, Graphify, Context7, Entire,
  GitHub, and existing skills/plugins before custom memory, tracing, eval,
  orchestration, MCP, permission, sandbox, navigation, or PR-intelligence code.

Registry code is untrusted until reviewed. Discovery is not approval.
